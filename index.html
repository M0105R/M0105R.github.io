A practical practice, built on clear evidence.

Analytics and machine learning, with a bias toward the useful.

I'm an AI and data science student in Paris, focused on the practical middle ground between raw data and the decisions it should inform.

My work spans analytics and machine learning. In industry, I've built end-to-end Power BI reporting — integrating OData sources, shaping data in Power Query, modelling it, and writing the DAX that turns it into KPIs, ticket aging, and month-to-date / year-to-date performance views.

Alongside that, I build machine-learning systems: a real-time air-quality forecaster with personalised asthma alerts, and a CNN that recognises handwritten digits from a live webcam feed. I care about the unglamorous middle — cleaning the data, checking the model, and making the result useful outside the notebook.

Outside of work, I've coordinated a department magazine, organised technical events with Google Developer Student Clubs, and reached the Smart India Hackathon finals with a gamified constitutional-literacy platform.

— Monisha

Case 01 · Machine learning · Health

Air Quality Forecast & Asthma Alert System

A real-time air-quality monitoring and forecasting system built on live CPCB AQI data, with personalised asthma alerts and interactive health dashboards.

Objective
Monitor live air quality and give asthma patients timely, personalised warnings.
Approach
Integrated live CPCB AQI data with a machine-learning forecasting pipeline in Python and Streamlit, then added personalised alert logic, health advice, and interactive dashboards.
Outcome
A working real-time system that brings forecasts, alerts, and visual monitoring into one interface.

Case 02 · Computer vision · Deep learning

Real-Time Handwritten Digit Recognition

A CNN trained on MNIST and paired with an OpenCV pipeline that captures, processes, and classifies handwritten digits from a live webcam feed.

Objective
Recognise handwritten digits in real time from a camera.
Approach
Trained a convolutional neural network on the MNIST dataset with Python and TensorFlow, then built an OpenCV pipeline for live capture and preprocessing.
Outcome
A live system that classifies handwritten digits as they are drawn.
